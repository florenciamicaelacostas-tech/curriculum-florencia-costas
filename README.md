# TP 1 - Currículum Vitae

## Descripción del trabajo:
El TP 1 se realizó para la materia Computación 3, este trabajo consiste en crear una página web que contenga información sobre nuestro currículum vitae utilizando html5, css y propiedades flexbox. 
En el header coloqué un gif decorativo y una barra de navegación. Dentro del main organicé la información principal del cv, primero presenté mi nombre y perfil profesional y luego las distintas secciones. Dentro de esas secciones incorpore imágenes, texto y listados.
En el footer agregué la ubicación y una sección con enlaces a mis redes sociales.

## Tamaño de pantalla:
Se realizó en una pantalla de 1360 x 780

## Editor de código:
Se utilizó Visual Studio Code

## Proceso:
A lo largo del trabajo tuve algunas dificultades para agregar las propiedades flexbox, fue quizás lo que mas me costó. Al principio al estar todas las propiedades y conceptos en ingles se me hizo difícil entenderlas.
También tuve problemas para al incorporar la tipografía, en una corrección me recomendaron cambiar el formato, pero cuando lo hice se dejó de aplicar la fuente a la página, por eso decidí mantener el formato de truetype como aparecía en el video tutorial de la materia.
En cambio el html, creo que fue lo que mas entendí, pude entender mejor la estructura y la funciones de las etiquetas.
En cuanto al diseño, me hubiera gustado poder desarrollarlo un poco mas, probar otra paleta de colores, aunque voy a seguir trabajándolo e ir agregando algunos elementos. Igualmente estoy conforme con el resultado, porque es mi primer acercamiento a todo este mundo web.
