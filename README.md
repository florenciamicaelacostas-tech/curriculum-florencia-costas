TP 3 - Portfolio

Descripción del trabajo:
El TP 3 se realizó para la materia Computación 3 y dicho trabajo consiste en crear una página web que contenga información sobre nuestro portfolio utilizando html5, css y propiedades flexbox vistas en el primer tp, a eso se le suma otras propiedades css como posiciones, formularios, galeria, entre otras.

Tamaño de pantalla:
El trabajo se realizó en una pantalla de 1360 x 780

Editor de código:
Se utilizó Visual Studio Code

Proceso:
Fue un gran desafío poder realizar este tp, pero estoy muy conforme con el resultado. Costó, si, pero siento que lo llevé mejor que la primera parte. Lo que mas me costó en esa etapa es realizar la galería ya que era linkear muchos html; intenté realizar todas estas cosas en JavaScript pero como verán, no pude. Pero estoy contenta con el resultado.
